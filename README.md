# js-fundamentals-demos
"Three JS demos: counter, to-do list, quiz"
## Files
- **counter.html** -increment/decrement/reset counter
- **todo-list.html** -add,complete and delete tasks
- **quiz.html** -multiple choice quiz with live scoring
## Concepts Covered
- Variables, scope, closures
- DOM Manipulation
- Arrays and Objects
- Functions and Control flow
